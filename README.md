# Sumplus Assay

Hiring an agent should be provable, not assumed. Assay runs the job both ways
and puts the difference on chain.

Built for **BNB Chain Build the Era**, aimed at the **TermiX** challenge.

## The question this answers

Every agent marketplace tells you an agent is good. None of them tell you it was
better than doing the job yourself, and that is the only question a buyer
actually has. TermiX asks for exactly that comparison, in an Agent Advantage
Report: real tasks, agent against manual, time and cost and quality for each.

Most entries will fill that report in by hand at the end. In Assay the report is
the product. It is generated by running both paths for real, and each run leaves
a receipt on BNB Smart Chain testnet that anyone can check afterwards.

## How a task runs

An assay is one task run twice.

1. **The manual path.** A scripted baseline that does what a person would do:
   fetch the same public data by hand, work through it step by step, and record
   how long it took and what it cost.
2. **The agent path.** The agent does the same task under a spending mandate:
   a per-task ceiling, a host allowlist, and a wallet that cannot exceed either.
3. **The comparison.** Time, cost and a quality score measured the same way for
   both paths, against the same inputs, in the same run. A comparison drawn from
   two different moments is not a comparison.
4. **The receipt.** The hash of the whole assay goes on chain, so the report
   cannot be quietly edited into a better one after the fact.

## Why the receipt matters here

An advantage report is a claim about your own product, written by you, scored by
someone who was not in the room. Anchoring each run means a judge can take the
report, recompute the hash from the numbers in it, and find that hash in a block
that predates the submission. The report stops being a claim and becomes a
record.

Receipts are chained: each commits to its own fields and to the hash of the one
before it, and the verifier recomputes the chain from the receipts, trusting
none of the stored hashes.

## The four categories

BNB Chain's brief names four kinds of agent, and Assay covers them evenly
because an advantage shown in one category says nothing about the others.

| Category | The task being assayed |
|---|---|
| Monitoring | Watch a pool and report the state that would trigger an action |
| Grid trading | Work out the grid a range implies and what it would have earned |
| Health factor | Read a loan position and say how far it is from trouble |
| Yield | Compare where capital sits against where it could sit |
